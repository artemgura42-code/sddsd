# ChessVision 2 — тестовый полный проект

Android-проект Kotlin. Включает захват экрана, экспериментальное обнаружение шахматной доски, ввод/редактирование FEN, UCI-клиент Stockfish, анализ позиции и плавающую стрелку поверх других приложений.

## Важно
Это **тестовая сборка для проверки**, а не сертифицированное приложение. Распознавание фигур сделано эвристически по визуальным признакам и зависит от темы/масштаба/антиалиасинга доски. На произвольных темах Lichess и Chess.com оно может ошибаться. В проекте предусмотрен ручной FEN как резервный способ проверки движка и стрелок. Нужны реальные скриншоты с твоего телефона, чтобы улучшить классификатор.

## Что внутри
- Android 8+ (minSdk 26), Kotlin, Gradle.
- MediaProjection захват экрана.
- Поиск квадратной шахматной доски по чередованию яркости.
- Экспериментальная классификация фигур по локальным признакам.
- FEN-поле и отправка `position fen` в UCI.
- Stockfish 19 ARM64 загружается на этапе GitHub Actions вместе с официальной NNUE.
- Анализ `go depth 14`, разбор `bestmove`.
- Overlay-стрелка (нужно разрешить отображение поверх других окон).
- GitHub Actions собирает debug APK и публикует artifact.

## Сборка
1. Создай пустой GitHub-репозиторий.
2. Распакуй содержимое ZIP в корень репозитория.
3. Загрузи все файлы в GitHub (включая `.github/workflows/android.yml`).
4. Открой Actions → Android debug build → Run workflow.
5. Скачай `ChessVision2-debug-apk` из завершённого запуска.

Workflow скачивает Stockfish 19 ARM64 и NNUE. Для устройства с ARM64 (большинство современных Android) это целевой ABI.

## Первый запуск
1. Открой приложение и нажми «Захват экрана».
2. Подтверди системный запрос Android.
3. Разреши «Поверх других приложений» для стрелки.
4. Открой позицию в Lichess или Chess.com, затем вернись в приложение.
5. Нажми «Анализировать текущий FEN» (для первой проверки проще вставить FEN вручную).
6. После анализа приложение покажет лучший ход и попытается нарисовать стрелку.

## Проверка движка без распознавания
Стартовая позиция уже заполнена в поле FEN. Нажми «Анализировать FEN». Если артефакт собрался и Stockfish успешно распакован, появится `bestmove`.

## Ограничения текущей тестовой версии
- Автоматическое распознавание фигур — исследовательская эвристика, не нейросетевая модель; не гарантирует точность на всех наборах фигур.
- Автоматическая реконструкция истории ходов, рокировки и en-passant невозможна по одному кадру. Для точного анализа позиции с историческими правами используй FEN из источника или ручной ввод.
- Стрелка позиционируется относительно найденной доски и требует проверки ориентации/координат на устройстве.
- В этой версии нет доступа к внутренним API Lichess/Chess.com: обработка выполняется по изображению экрана.
- Для ARM32 и x86 Android бинарник Stockfish в workflow пока не загружается.
- Проект не проходил тестирование на твоём конкретном телефоне. Сообщения об ошибках и скриншоты нужны для дальнейшей отладки.
